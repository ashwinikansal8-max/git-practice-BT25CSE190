## Exercise 02: Word statistics

`exercise-02/wordstats.sh` prints the number of newline-terminated lines, words,
and characters (including newline characters) in a text file. It accepts a file
path as an argument and uses `input.txt` in the current directory when no path
is provided. If the file cannot be found, it prints an error and exits with a
nonzero status.

Run it in Git Bash from the exercise folder:

```bash
cd exercise-02
bash wordstats.sh
```

The sample output is saved in `exercise-02/output.txt`.
